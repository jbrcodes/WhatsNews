This website displays a selection of article summaries, translated into English, from a few selected foreign-language news websites. The summaries are updated several times a week.

The summaries for each site fall into one of two categories:

  • Headlines are retrieved using a web scraper that reads the site's home page and attempts to identify and extract the main headlines.
  • Summaries for sites labeled as various are read from an RSS feed, provided by some websites. An RSS feed lists the published articles, typically with the most recently published article listed first (versus the most newsworthy article).

English translations are displayed by default. To see the original foreign language texts, select the original language from the pull-down menu for each site.

For more information, see A Glimpse into Foreign-Language News.
